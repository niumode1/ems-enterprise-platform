# 企业人员组织与项目文档协同管理系统

单租户、每家公司独立部署的企业人员与项目协同系统。系统覆盖员工档案、双组织视图、自定义属性、审计与版本回滚、AI 花名册导入、项目/任务/里程碑、文档权限、聊天、通知和 AI 助手。

## 技术栈

- 后端：Spring Boot 3.3 / Java 21 / MyBatis-Plus / Flyway / MySQL 8+（本地开发已用 MySQL 9.5 验证）
- 前端：Vue 3.5 / Vite 5 / TypeScript / Element Plus / Pinia / Vue Router
- 文件存储：本地磁盘适配器（`app.storage.local-path`），MinIO/S3 适配预留
- AI：P1 接入 OpenAI-compatible 外部 API，Ollama/vLLM 本地适配预留
- 实时：原生 WebSocket（`/api/v1/ws`），聊天与站内通知实时推送，开关/心跳/连接数可配；Redis 仅在需要多实例时引入
- 部署：Docker Compose + Nginx

## 模块

| 模块 | 说明 |
|---|---|
| 身份与权限 | 账号、角色、RBAC、数据范围、字段级权限 |
| 员工与组织 | 多岗位/多部门、行政树、汇报树、员工关系气泡图、岗位履历 |
| 自定义属性 | 不改表新增属性，支持时间线属性 |
| 审计与版本 | 不可变日志、字段 diff、版本快照、回滚 |
| 初始化导入 | AI 抽取草稿、管理员校对、员工确认、批次回滚 |
| 项目与任务 | 项目成员、任务、里程碑、进度 |
| 文档库 | 项目级 + 文档级权限、版本追加、预览、下载 |
| 公司制度 | 公司级规章制度上传、查看、下载、AI 问答与全局搜索 |
| 聊天 | 一对一、群聊、保留期、阅后即焚、防撤回、管理员限时只读查看 |
| 通知 | 站内消息中心、待办提醒 |
| AI 助手 | 花名册解析、文档问答、人员问答、操作入口推荐 |
| 配置中心 | 初始化向导、策略配置、配置审批 |

## 快速启动

### 依赖服务

```bash
docker compose up -d
```

默认端口：MySQL `3306`、Redis `6379`、MinIO `9000/9001`、Elasticsearch `9200`（`--profile search`）。

### 后端

```bash
cd backend
mvn spring-boot:run
```

后端默认地址：`http://localhost:8080`，健康检查：`http://localhost:8080/api/v1/health`。

### 前端

```bash
cd frontend
npm install
npm run dev
```

前端默认地址：`http://localhost:5173`。
