# 决策记录

日期：2026-11-08  
状态：v1.1 基线

| # | 决策项 | 结论 | 说明 |
|---|---|---|---|
| 1 | 部署形态 | 单租户，每家公司独立部署 | 不做多租户 SaaS，数据隔离靠独立部署 |
| 2 | 后端/前端 | Spring Boot + Vue 3 | 用户指定 |
| 3 | 数据库 | MySQL 8 主库 | 性能优先。P0 仅依赖 MySQL + 本地磁盘文件存储；Redis / MinIO / Elasticsearch 按需在后续阶段引入，不提前增加部署复杂度 |
| 4 | 到岗打卡 | 整块删除 | 定位、地理围栏、Beacon、位置上报接口都不做 |
| 5 | 文档权限 | 方案 A：项目角色 + 文档继承 + 单文档例外 | 支持项目级和文档级 |
| 6 | 外链分享 | 关闭 | 所有信息仅公司内部按权限查看 |
| 7 | 在线编辑 | 不做 | 文档只支持上传新版本，不覆盖旧版本 |
| 8 | 文档删除 | 硬删除，不保留 | 业务数据和文件存储删除；备份/审计元数据按策略自然留存 |
| 9 | 文档保留期 | 项目发起时由发起者设置 | 到期动作可配置（归档/删除/提醒） |
| 10 | 老板查看敏感信息 | 方案 B | 默认脱敏，提交申请，管理员审批，限时查看，全程日志 |
| 11 | 关键信息修改 | 多人审批，不能单人修改 | 关键字段、审批人数、通过人数、申请人是否计入均可配置 |
| 12 | 审批配置修改 | 按初始化时设定的审批规则通过后才能改 | 防止管理员随意放宽审批 |
| 13 | 审计日志 | 不可手动删除；到期自动清理；清理动作留痕 | 不做敏感访问实时告警，日志用于追溯 |
| 14 | 审计员 | 可单独设置，也可由其他角色兼任 | 只读审计权限 |
| 15 | 紧急恢复 | 设计恢复通道 | 老板 + 审计员双签，或部署级恢复账号 |
| 16 | AI 部署模式 | v1 外部 API，预留本地适配 | 管理员初始化时选择外部/本地；本地联调二期 |
| 17 | AI 可读范围 | 管理员配置 | 哪些字段可被 AI 读取、哪些可快速问，均配置化 |
| 18 | AI 操作指引 | 返回可能入口，点击跳转 | 不做可视化步骤演示 |
| 19 | AI 文档问答 | 必须带原文出处/文档链接 + 低置信提示 | 低置信提示“请咨询组长” |
| 20 | AI 回答风格 | 简短回答 | 不展开长篇 |
| 21 | 聊天范围 | 一对一 + 群聊 | 文字、图片、文档；大小/保留期/群人数可配 |
| 22 | 聊天隐私 | 管理员默认不能看内容 | 查看极敏感消息需多管理员/相关人员同意，全程审计 |
| 23 | 聊天特殊功能 | 阅后即焚、防撤回可配置 | 只能做到服务端/客户端删除，无法防截图 |
| 24 | 项目范围 | 项目 + 成员 + 任务 + 里程碑 + 进度 + 文档 | 任务/里程碑/进度的创建编辑删除权限可配 |
| 25 | 项目视图 | v1 列表/详情/进度条/里程碑列表 | 甘特图、看板二期 |
| 26 | 员工组织 | 一人可多岗位、多部门 | 行政树与汇报树分离；可见范围由管理员配置 |
| 27 | 自定义属性 | 不改表结构 | EAV/JSON + 时间线明细表；可搜索字段建索引 |
| 28 | 导入格式 | 一期 Excel 模板 + Word/PDF | 扫描件 OCR 二期 |
| 29 | 通知 | 站内消息中心 | 邮件/企业微信/钉钉预留，二期可接 |
| 30 | 性能 | 性能优先 | 索引、缓存、异步、搜索索引、读模型 |
| 31 | 规模 | 暂按中小规模设计，可扩展 | 具体员工数/文档量/并发后续补充 |
