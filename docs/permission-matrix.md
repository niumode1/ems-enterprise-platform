# 角色权限矩阵

> 本文件定义 v1.1 的默认权限。实际权限由配置中心初始化时设置，后续按审批规则修改；代码不写死角色。

## 1. 角色

| 代码 | 角色 | 定位 |
|---|---|---|
| `BOSS` | 老板 | 全局查看、审批；敏感信息按申请-审批-限时访问 |
| `SYS_ADMIN` | 系统管理员 | 账号、角色、配置、AI 配置、审计配置；默认不含人事敏感字段 |
| `HR_ADMIN` | HR 管理员 | 员工、组织、导入、人事字段维护 |
| `DEPT_LEADER` | 行政组长 | 行政部门子树内人员与数据 |
| `PROJECT_LEADER` | 项目组长/负责人 | 项目成员、任务、里程碑、文档权限 |
| `EMPLOYEE` | 普通员工 | 权限内查看、本人字段维护、项目/聊天/AI |
| `AUDITOR` | 审计员 | 只读审计日志，可由其他角色兼任 |

## 2. 数据范围

| 代码 | 范围 | 说明 |
|---|---|---|
| `SELF` | 本人 | 仅本人档案、本人任务、本人会话 |
| `DIRECT_REPORTS` | 直属下级 | 主汇报关系下的直接下属 |
| `DEPT_SUBTREE` | 部门子树 | 当前行政组织及全部下级 |
| `PROJECT_MEMBER` | 项目成员 | 当前项目成员 |
| `PROJECT_OWNER` | 项目负责人 | 当前项目负责人/管理员 |
| `ALL` | 全公司 | 老板、特定管理员 |

## 4. 字段级权限

管理员为每个字段配置：

| 配置项 | 取值 | 示例 |
|---|---|---|
| 可见角色/范围 | 角色 + 数据范围 | 手机号：本人、HR、直属上级 |
| 展示方式 | 明文 / 脱敏 / 隐藏 | 手机号：`138****1234` |
| 本人可编辑 | 是 / 否 | 手机号可改；薪资不可改 |
| 导出权限 | 是 / 否 | 身份证默认不可导出 |
| AI 可读 | 是 / 否 | 薪资默认 AI 不可读 |
| 修改是否关键 | 是 / 否 | 薪资、身份证、银行卡为关键 |

默认建议：

| 字段组 | 默认可见 | 默认展示 | 本人可编辑 | 关键信息 |
|---|---|---|---|---|
| 姓名、工号、部门、岗位 | 权限内用户 | 明文 | 否 | 岗位变更算关键 |
| 手机、邮箱、办公地点 | 本人、直属上级、HR、项目成员（可配） | 明文/脱敏 | 是 | 否 |
| 身份证、银行卡 | 本人、HR、审批通过者 | 脱敏 | 否 | 是 |
| 薪资、绩效、工资时间线 | 本人、HR、审批通过者 | 脱敏 | 否 | 是 |
| 家庭住址、紧急联系人 | 本人、HR | 脱敏 | 是 | 否 |
| 自定义属性 | 按属性定义 | 按属性定义 | 按属性定义 | 按属性定义 |

## 5. 文档权限

### 5.1 项目角色默认动作

| 动作 | 负责人 | 管理员 | 成员 | 只读 |
|---|---|---|---|---|
| 预览 | 是 | 是 | 是 | 是 |
| 下载 | 是 | 是 | 可配 | 可配 |
| 打印 | 是 | 是 | 可配 | 可配 |
| 上传新版本 | 是 | 是 | 可配 | 否 |
| 删除 | 是 | 可配 | 否 | 否 |
| 授权管理 | 是 | 可配 | 否 | 否 |
| 外链分享 | 否 | 否 | 否 | 否 |

- 文档默认继承项目权限。
- 单文档可覆盖：加人/减人、调整动作。
- 外链分享全局关闭。
- 项目负责人决定谁可上传、谁可删除。
- 删除为硬删除；下载/打印按查看者权限判断。

### 5.2 权限判断顺序

1. 用户是否项目成员/负责人。
2. 文档是否有单文档 ACL 覆盖。
3. 动作是否在允许列表。
4. 外链请求一律拒绝。
5. 记录访问日志。

## 6. 审批规则

| 规则 | 默认 | 可配置 |
|---|---|---|
| 关键字段 | 薪资、身份证、银行卡、岗位、上级、部门、项目归属、权限 | 是 |
| 通过人数 | 2 | 是 |
| 申请人是否计入 | 否 | 是 |
| 审批配置修改所需人数 | 2 | 是 |
| 审批超时 | 24 小时提醒，72 小时关闭 | 是 |
| 紧急恢复 | 老板 + 审计员双签，或部署级账号 | 是 |

- 关键信息不能单人修改。
- 发起人默认不能审批自己的申请。
- 导入提交、回滚、权限变更如涉及关键字段，走同一审批引擎。
- 所有审批动作留痕。

## 7. 老板敏感访问

| 配置 | 默认 | 说明 |
|---|---|---|
| 默认展示 | 脱敏 | 老板也只能先看脱敏值 |
| 申请内容 | 用途、字段范围、有效时长 | 必填 |
| 审批人数 | 1 | 可配 |
| 有效期 | 30 分钟 | 可配 |
| 日志 | 申请、审批、查看、过期 | 全部记录 |
| 通知 | 审批人、审计员 | 可配 |

## 8. 审计员

- 可查看审计日志、访问日志、版本记录、审批记录。
- 不可修改业务数据、不可删除日志。
- 可由老板/HR/系统管理员兼任，但任命需留痕。
- 敏感日志查看本身也记录。

## 9. 越权测试清单

- 普通员工读取他人薪资/身份证。
- 组长读取非本部门员工。
- 项目成员读取非本项目文档。
- 被移除项目成员继续下载文档。
- 老板未审批直接看明文。
- 单人修改关键信息。
- 申请人审批自己的申请。
- 审计员修改业务数据。
- 管理员删除审计日志。
- AI 读取无权限字段/文档。
- 外链访问被拒绝。
