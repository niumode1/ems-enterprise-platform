# 企业人员组织与项目文档协同管理系统 需求文档 v1.1

- 版本：v1.1
- 日期：2026-11-08
- 状态：基线，可进入开发
- 部署形态：单租户，每家公司独立部署

## 1. 项目目标

为企业提供一套内部使用的人员组织与项目文档协同系统，覆盖员工档案、组织关系、项目协作、文档权限、审计追溯和 AI 辅助。系统由每家公司独立部署、独立配置，业务规则不写死。

## 2. 架构约束

- 后端：Spring Boot 3.x，Java 21。
- 前端：Vue 3 + Vite + TypeScript。
- 数据库：MySQL 8 主库。
- 缓存/会话/消息：Redis。
- 文件存储：MinIO（S3 兼容）。
- 搜索：Elasticsearch + IK 中文分词（可选；小规模可先用 MySQL）。
- 实时通信：WebSocket(STOMP) + Redis Pub/Sub。
- AI：v1 接外部 OpenAI-compatible API；预留 Ollama/vLLM 本地适配。
- 部署：Docker Compose 起步，Nginx 反向代理。
- 架构风格：模块化单体。后续按负载拆分，不提前微服务化。
- 性能优先：合理索引、缓存、异步任务、读模型、搜索索引；避免纯 EAV 全表 JOIN。

## 3. 角色与权限

### 3.1 角色

| 角色 | 说明 |
|---|---|
| 老板 | 全局查看与审批；敏感信息按“申请-审批-限时”访问 |
| 系统管理员 | 账号、角色、系统配置、AI 配置、审计配置；默认不查看人事敏感字段 |
| HR 管理员 | 员工档案、组织、导入、人事字段维护；关键信息修改需多人审批 |
| 行政组长 | 管理行政部门子树内的人员与数据 |
| 项目组长/项目负责人 | 管理项目成员、任务、里程碑、文档权限 |
| 普通员工 | 查看权限内信息，维护本人可编辑字段，参与项目/聊天/AI |
| 审计员 | 只读审计日志；可由其他角色兼任 |

### 3.2 权限模型

权限 = 角色 + 操作权限 + 数据范围 + 字段权限。

- 操作权限：RBAC 权限点，不把权限写死在角色代码里。
- 数据范围：本人、直属下级、部门子树、项目成员、项目负责人、全公司。
- 字段权限：管理员按字段配置“可见角色/范围、明文或脱敏、本人是否可修改”。
- 角色、权限点、数据范围均可由管理员配置。
- 所有敏感字段的查看、导出、下载、分享、AI 查询都记访问日志。

### 3.3 关键信息审批

- 哪些字段算“关键信息”、需要几人审批、几人通过、申请人是否计入，均由系统初始化时配置。
- 关键信息不能单人修改。采用 maker-checker：一人提交，其他人审批。
- 修改“审批规则本身”也要按初始化时设定的规则审批通过。
- 导入提交、版本回滚、权限变更如涉及关键字段，同样走审批。
- 预留紧急恢复通道：老板 + 审计员双签，或部署级恢复账号。

### 3.4 老板访问敏感信息

- 默认只看到脱敏值。
- 查看明文需提交申请：填写用途、查看范围、有效时长。
- 由配置数量的管理员审批，审批通过后在有效期内查看。
- 每次查看、审批、过期都记审计日志。
- 审批人数、有效期、可审批人由配置中心设置。

### 3.5 审计员

- 只读审计日志、访问日志、版本记录、审批记录。
- 不能修改业务数据。
- 可由老板、HR、系统管理员等角色兼任。
- 审计员任命由管理员配置并留痕。

## 4. 功能需求

### 4.1 账号与登录

- 用户名/密码登录，JWT 访问令牌 + 刷新令牌。
- 登出、修改密码、重置密码。
- 可选 MFA（管理员配置）。
- 登录失败锁定、会话超时。
- 账号状态：启用、禁用、锁定。
- 账号与员工档案可关联；员工可以没有账号。
- 登录日志：成功/失败、IP、User-Agent、时间。

### 4.2 员工档案

- 基础字段：姓名、工号、性别、出生日期、手机、邮箱、身份证、地址、紧急联系人、头像、入职日期、状态等。
- 字段目录、是否必填、是否敏感、脱敏规则、本人是否可编辑，由管理员配置。
- 敏感信息允许不填写；填写后按字段权限展示。
- 一名员工可属于多个部门、多个岗位，设置主部门/主岗位。
- 岗位履历时间线：生效日期、结束日期、部门、岗位、汇报上级、变动原因。
- 汇报关系：支持主汇报/虚线汇报、多上级；记录生效区间。
- 员工状态：在职、试用、休假、离职；离职归档，不物理删除历史。
- 员工搜索、筛选、导出；导出需权限并记日志。
- 员工档案修改留 before/after diff，可回滚。

### 4.3 组织视图

- 行政组织树：组织单元、上级、负责人、排序、路径、状态。
- 业务汇报树：按汇报关系生成，可与行政树不同。
- 查看人员的上级、同级、下级；“同级”按当前视图定义（同部门/同直属上级/同项目角色）。
- 一人多岗位时，在树中可出现多次，标记主岗位。
- 组织树可见范围可配置：全公司、本部门子树、仅本人链条。
- 组织调整、汇报关系调整留审计和版本。

### 4.4 自定义属性

- 管理员在页面新增属性，不需要改数据库表结构。
- 属性定义：编码、名称、适用对象（员工/项目）、类型、必填、唯一、可搜索、可排序、可见角色、脱敏规则、本人可编辑、选项、校验规则、分组、排序。
- 类型：文本、长文本、数字、小数、日期、日期时间、布尔、单选、多选、文件、时间线。
- 时间线属性（如工资时间线）：记录生效日期、结束日期、金额、绩效、发放时间、币种、变更原因等，独立明细表存储。
- 属性值支持版本和审计。
- 可搜索属性建立索引或同步到 Elasticsearch；不做“任意属性任意组合实时报表”的承诺。
- 属性删除、类型变更需迁移策略和审批。

### 4.5 审计与版本

- 审计日志字段：操作人、时间、IP、User-Agent、模块、动作、对象类型、对象 ID、修改前、修改后、diff、原因、审批单号、trace ID。
- 日志分类：敏感查看、日常操作、登录、导出、下载、分享、AI 查询、配置变更、审批、导入、回滚。
- 日志不可手动删除；按配置保留期到期自动清理；清理动作本身记日志。
- 不做敏感访问实时告警；日志用于追溯。
- 员工、项目、成员关系、自定义属性值、文档元数据做版本快照 + 字段级 diff。
- 回滚 = 用旧快照生成新版本，不删除历史；回滚需审批并留痕。
- 版本号/乐观锁防止并发覆盖。
- 审计查询支持按人、时间、模块、对象、敏感/日常筛选。
- 敏感数据的查看、导出、下载、分享、AI 查询记访问日志。

### 4.6 初始化批量导入

- 管理员上传花名册：一期支持 Excel 模板、Word、PDF；扫描件 OCR 二期。
- AI 抽取人员、岗位、上下级、所属项目，输出结构化 JSON，字段带置信度和来源位置。
- 识别结果进入草稿，不直接落库。
- 流程：上传 → 解析 → 草稿 → 管理员预览校对 → 推送员工确认 → 员工确认/编辑/驳回 → 管理员处理 → 提交 → 可批次回滚。
- 校验：身份证校验位、手机格式、日期、上级是否存在、汇报链是否成环、部门/项目是否存在、重复人检测。
- 老员工匹配键可配置（工号 > 身份证哈希 > 手机 > 邮箱 > 姓名+部门）。
- 字段级记录来源：AI、管理员、员工、规则；低置信字段高亮，必须人工确认。
- 员工确认时只能编辑管理员允许的字段；驳回需填原因。
- 导入提交如涉及关键信息，走多人审批。
- 导入批次可整体回滚；部分失败可重试。
- 所有操作留痕，记录 AI 厂商/模型/提示词版本/文件哈希。

### 4.7 项目、任务与里程碑

- 项目：名称、编码、描述、负责人、成员、状态、起止日期、可见范围、保留期。
- 项目角色：负责人、管理员、成员、只读；权限可配置。
- 成员管理：邀请、移除、角色调整；留审计。
- 任务：标题、描述、负责人、参与人、优先级、状态、开始/截止日期、依赖、附件、评论、进度。
- 任务状态：待办、进行中、已完成、阻塞、取消。
- 里程碑：名称、日期、交付物、状态、说明。
- 项目进度：手动填写或按任务完成率自动计算（可配置）；保存进度快照。
- v1 界面：任务列表/详情、进度条、里程碑列表；甘特图、看板二期。
- 任务/里程碑的创建、编辑、删除权限由公司配置。
- 任务分配、到期、状态变更触发通知。

### 4.8 文档库

- 每个项目配套文档库，支持文件夹组织（文件夹不单独分权，权限按项目/文档）。
- 文档上传、预览、下载、打印、版本追加、删除、搜索。
- 不做在线编辑；上传新版本形成版本链，当前版本可切换，旧版本保留。
- 项目级权限 + 单文档权限覆盖（方案 A）：
  - 项目角色：负责人、管理员、成员、只读。
  - 文档默认继承项目权限；敏感文档可单独加人/减人。
  - 权限动作：预览、下载、打印、上传新版本、删除、授权管理。
  - 不同权限对应不同允许动作，由项目负责人配置。
- 项目负责人决定谁可以上传、谁可以删除。
- 删除为硬删除，不保留回收站；业务数据和文件存储删除；备份和审计元数据按策略留存。
- 文档保留期由项目发起者在创建项目时设置；到期动作可配置（归档/删除/提醒）。
- 外链分享关闭，所有文档仅公司内部按权限访问。
- 上传类型/大小校验、病毒扫描、短期签名 URL、预览转换。
- 文档查看、下载、打印、删除、权限变更全部审计。

### 4.9 聊天

- 一对一私聊 + 群聊。
- 消息类型：文字、图片、文档；文件大小上限可配。
- 群聊：创建、成员管理、群主、管理员、禁言、@、群公告；群人数上限可配。
- 消息保留期可配；到期自动清理。
- 群聊可开启阅后即焚、防撤回：
  - 阅后即焚：可设为群级或单条消息；服务端到期删除，客户端移除。无法阻止截图。
  - 防撤回：开启后禁止撤回；关闭时允许撤回并显示撤回提示。
- 管理员默认不能查看聊天内容，只能看元数据。
- 查看“极敏感消息”需发起申请，由配置数量的管理员或相关人员同意，限时查看，全程审计；具体审批规则可配。
- 消息实时送达、未读、已读回执（可配）、离线通知。
- 聊天文件独立权限，不能绕过项目文档权限。
- 聊天搜索仅限本人有权限的会话。

### 4.10 通知

- 站内消息中心：消息列表、未读数、已读、分类、深链跳转。
- 事件：待确认档案、审批待办、项目邀请、任务分配/到期、文档分享、聊天@、系统公告。
- 通知模板、用户偏好、去重、聚合、保留期可配。
- 邮件、企业微信、钉钉、飞书预留接口，二期可接。

### 4.11 AI 助手

- 管理员初始化时选择 AI 模式：外部 API / 本地模型（v1 外部 API，本地适配器预留）。
- 外部模式配置：厂商、Base URL、API Key（加密存储）、模型、参数；支持测试连接。
- 每个 AI 功能可单独选择模型（花名册解析、文档问答、人员问答、操作指引）。
- 管理员配置 AI 可读字段、可快速问的字段、脱敏规则。
- 花名册解析：见 4.6。
- 人员问答：自然语言查询岗位、上级、联系方式、自定义属性；受字段权限和脱敏约束；同名员工消歧；回答简短并标注来源。
- 文档问答：只读取当前用户有权限的项目文档；回答必须带原文出处/文档链接；低置信提示“请咨询组长”；回答简短。
- 操作指引：维护帮助索引（标题、关键词、路由、适用角色）；用户提问后返回最多 3 个可能入口，点击跳转；不做可视化步骤演示。
- AI 审计：用户、问题、功能、模型、检索文档 ID、token、耗时、回答摘要；保留期可配。
- 配额/成本：按用户/部门配置每日调用上限，超限提示；失败降级。
- 安全：文档内容视为不可信输入，防提示词注入；人员问答走受权限控制的工具调用，不直接生成 SQL；外部模型模式在初始化时提示第三方数据处理风险。
- AI 不能自动提交数据，所有落库操作必须人工确认。

### 4.12 配置中心

- 首次初始化向导：公司信息、初始管理员、安全策略、审批策略、审计保留、AI 模式、聊天策略、文档策略、通知策略。
- 配置带版本、变更审计；关键配置修改走审批。
- 配置按公司隔离（单租户部署下即本系统）。
- 紧急恢复：老板 + 审计员双签，或部署级恢复账号。

### 4.13 全局搜索

- 搜索员工、项目、任务、文档。
- 权限感知：只返回当前用户可见结果。
- 中文全文检索，支持筛选、高亮、分页。
- 文档搜索需在权限过滤后返回。

### 4.14 已删除范围

- 到岗打卡、地理围栏、蓝牙 Beacon、位置上报接口：不做。
- 文档外链分享：不做。
- 文档在线编辑：不做。
- 原生 App：不做（前端为响应式 Web）。
- 本地大模型联调：v1 不做，预留适配。
- 甘特图/看板：二期。
- 扫描件 OCR：二期。
- 邮件/企业微信/钉钉通知：预留，二期。

## 5. 关键流程

### 5.1 导入流程状态机

`UPLOADED → PARSING → DRAFT → ADMIN_REVIEW → PUSHED → EMPLOYEE_CONFIRMED / EMPLOYEE_EDITED / EMPLOYEE_REJECTED → COMMITTED / ROLLED_BACK`

- 解析失败可重试；部分行失败不影响其他行。
- 管理员可批量校对、单行修改、重新推送。
- 员工驳回后回到管理员处理。
- 提交前再次校验；关键字段走审批。

### 5.2 关键信息修改

`提交申请 → 审批人审批 → 达到通过人数 → 生效 → 记审计/版本`

- 申请人是否计入通过人数可配。
- 未通过可修改后重提。
- 审批超时可配置提醒/自动关闭。

### 5.3 老板查看敏感信息

`发起申请（用途/范围/时长）→ 管理员审批 → 限时查看 → 到期收回 → 全程审计`

### 5.4 文档权限判断

`用户 → 项目角色 → 文档是否有单文档覆盖 → 动作权限 → 允许/拒绝`

- 外链一律拒绝。
- 下载/打印按用户权限判断。
- 权限变更实时生效。

### 5.5 聊天管理员查看

`发起申请（理由/范围）→ 多管理员/相关人员审批 → 限时查看 → 审计 → 通知相关人（可配）`

- 默认不开放；无审批不能查看。

## 6. 非功能需求

### 6.1 性能

- 常用接口 p95 < 500ms；搜索 < 1s；AI 首 token < 3s；WebSocket 消息 < 500ms。
- 分页、索引、缓存、异步导入/解析、读模型。
- 审计日志按月分区；大表避免全表扫描。
- 具体员工数、文档量、并发在部署前补充，架构按可扩展设计。

### 6.2 安全

- HTTPS、JWT、刷新令牌、密码策略、登录锁定、可选 MFA。
- 管理后台最小权限；系统管理员默认不看人事敏感字段。
- API Key、身份证、银行卡等加密存储；界面掩码。
- 文件上传类型/大小校验、病毒扫描、签名 URL。
- 越权测试、依赖扫描、日志脱敏。
- 限流、防重放、防注入、XSS/CSRF 防护。

### 6.3 数据与合规

- 敏感个人信息单独告知/同意；员工可查看本人档案。
- 数据保留期、离职归档、审计日志保留可配。
- 外部 AI 模式需提示第三方数据处理风险，由公司确认。
- 备份：每日全量 + binlog；RPO/RTO 部署时配置。

### 6.4 可观测性

- 结构化日志、trace ID、指标、告警。
- 登录、权限变更、配置变更、AI 调用、导入任务可追踪。

## 7. 配置化原则

以下内容不写死，全部进配置中心，由每家公司初始化时设置，后续按审批规则修改：

- 关键信息字段、审批人数、通过人数、申请人是否计入。
- 审计员、日志保留期、自动清理。
- 老板查看审批人数、有效期。

## 9. 验收标准

- 权限矩阵可配置且越权测试通过。
- 关键信息单人无法修改；审批人数/通过人数可配。
- 老板敏感查看必须审批、限时、留痕。
- 审计日志不可手动删除，到期清理有记录。
- 员工/项目/属性/文档元数据可查看 diff 并回滚。
- 导入不直接落库；管理员可校对；员工可确认/编辑/驳回；批次可回滚。
- 文档权限按项目角色 + 单文档覆盖生效；外链被拒绝。
- 文档版本追加不覆盖；删除为硬删除；下载/打印按权限。
- 聊天保留期、阅后即焚、防撤回可配；管理员查看需审批。
- AI 人员问答受字段权限/脱敏约束；文档问答带出处和低置信提示；操作指引返回入口。
- 外部 AI 与本地 AI 模式可切换（本地适配器预留）。
- 紧急恢复通道可用。

## 10. 假设与待定

- 单租户，每家公司独立部署。
- 规模暂按中小规模设计；具体数字部署前补充。
- 前端为响应式 Web，不做原生 App。
- v1 只接外部 AI API；本地模型二期联调。
- 文档不做在线编辑；不做外链分享。
- 通知 v1 只做站内；其他渠道二期。
- 甘特图/看板、扫描件 OCR 二期。
